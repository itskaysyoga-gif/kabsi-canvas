## What this file is, and what it is not

- 12 hand-picked listings at most, submitted by hand by Rashid. There is no automated directory submission (30.50 item 12). None of the outside repositories of the 10 Nov growth brief is adopted, and no GitHub list is used (R-151).
- Nothing was submitted. No account was created on any site. No pull request, issue or comment was prepared for any outside repository. This session only read public pages and wrote this text.
- The copy to paste is in `docs/marketing/profile.md` and is pasted as it stands. The status column stays "Not submitted" until Rashid submits and writes the date.
- No scraping, no posting, no paid tool, no paid listing.

## Selection rule

A place where an owner, an agency or an AI answer engine actually looks for this kind of software. A site is dropped when it charges (a listing fee, a priority fee or a paid placement is the only way in), needs a reciprocal link or a badge on kabsi.co, or does not fit what Kabsi is. A free listing with an optional paid upgrade stays, and the upgrade is never bought.

## Link log

No link is treated as a ranking gain. A listing is a place people and answer engines can find Kabsi; it is not counted as ranking help, and no number in any report adds up links.

How to fill a row: when a listing goes live, open its page, read the `rel` attribute of the link to kabsi.co in the page's source, and write the kind: ordinary (no `rel` value that limits it), nofollow, or sponsored. Write the date it was read. Check each live row again every 6 months.
