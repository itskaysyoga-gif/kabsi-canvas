## Rules for this video

- Tag "AI presenter" for the first 3 s. Paid cuts add "Presenter is AI-generated."
- Never promise that a report removes a review. Google decides. The on-screen line says so.
- No review text from a real reviewer. S11 uses the invented demo review.
- Never suggest replying angrily, trading reviews, offering a reward to remove a review, or asking for a review to be changed.
