## Decisions made in the build (lane R may change them)

- PUBLISH_ALL_AT is "2026-11-05T15:05:00Z", set a few minutes before part A merged (it merged 15:0x UTC), so the guides were public from the first request after the deploy.
- The guides list keeps the Guides 3 order (guide 1 first, then 2 to 20, then the earlier seven). A guide scheduled after PUBLISH_ALL_AT (a weekly one) is listed first, newest first.
- The page list for Nora is a public JSON route (/nora-pages.json, noindex, at most a minute of cache) because the Edge Function cannot import the site's content. It holds only pages that are public at the request. The function keeps the last good list if the site does not answer.
- Industry pages in the list are the indexed ones (11 today; the dental clinic page waits for its claim sheet). Hubs are not in it: Industries 2 removes category pages. Industries 2 may change `industryIndexed` and the content shape; src/lib/public-pages.ts is the one file to adapt.
- lastmod: pages and their source files are in src/content/sitemap-pages.json; the build writes src/content/lastmod.json from git and keeps the committed file when Vercel's clone is short (LATER row). Industry pages use their content file's last commit day (they have no `updated` field).
- IndexNow's "changed since the previous deploy" is the files that changed between the previous successful Production deployment and this one, mapped to pages by the same source list; the daily run sends guides published in the last 24 hours.
- kabsi-canvas.vercel.app is the only *.vercel.app alias of the project; the redirect names that host exactly, so preview deployments (other hosts) are not touched.
