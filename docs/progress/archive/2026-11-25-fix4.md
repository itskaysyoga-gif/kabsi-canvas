## 2. mail_tester_score returned 409 no_score_yet

Two causes, both in `_shared/outbound/mail-tester.ts`:
- The URL `https://www.mail-tester.com/<id>&format=json` answers 301 to a page that serves HTML, so `.json()` failed and the
  reader saw "no score". The form that answers JSON is `https://www.mail-tester.com/<id>?format=json`.
- In the real report `mark` is `0` next to `displayedMark: "10/10"` and `commentedMark: "Your lovely total: 10/10"`. The reader
  trusted `mark`, so the URL fix alone would have recorded 0. It now reads `displayedMark`, then `commentedMark`, and `mark`
  only when it is above 0 and there is no text.
- Checked locally against the live report of `test-mvk4fxl2m`: the new reader returns 10.
- Recording the score is done by the deployed function after merge (After merge below).
