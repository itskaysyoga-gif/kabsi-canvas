## 5. Independent review

A fresh agent, given only the diff and the rules. Confirmed and fixed here:
1. High: names were read as days ("Sundar on friday at 2pm" became Sunday 14:00, "frida at 3pm" Friday 15:00), so a time was invented. Day and time typos are now read only inside the words quoted for when (tests: Sundar, Frida).
2. Medium: everyday words were read as services ("a message for a cut" gave Massage, "brown colour" Brows). A one-word service typo needs 6 letters, an everyday word list is never read, and a typo counts only when the rest of the quote fits (tests).
3. Medium: an old "Update #1" tap after the draft changed (or a made-up button) could write another customer's details onto #1, and the version was read at the tap. The button now holds a nonce only; the request and version sit in the open question and the duplicate is checked again (test).
4. Medium: Update changed one time field and not the other. Both now move together.
6. Medium to low: the reset SQL could count or close a request twice for a phone with two roles at one demo business. It uses exists and skips a row already closed.
7. Low: a first line with a colon then a full stop was all bold; "Dr." split early; a star in a name broke the bold. Fixed.
8. Low: "Write a story for Instagram" was caught as off topic. Instagram, Facebook, menus, captions and customers are never caught.

Noted, not changed: 5 (a revision that gives only a day part, "afternoon", replaces the stored day; the first message's "agreed" note is dropped on a revision) and 9 (a free-text past summary can become a service; a second tie in one message takes its first choice; reset test replaces an open proposal question). Kept on purpose: an unclear message from an owner gets the fixed off-topic line rather than the routing model's question, because R-148 item 5 says no model answer.
