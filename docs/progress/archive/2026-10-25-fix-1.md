## What changed

- **Webhook.** Kapso does not generate the signing key. `setupWebhook` makes 48 random characters, sends them as `whatsapp_webhook.secret_key`, and stores them with `whatsapp_set_webhook_secret` only after Kapso accepted the call. A webhook already on Kabsi's URL is updated (PATCH), never duplicated; nothing is deleted, so Kapso's own inbox webhook is untouched. Kapso's and Meta's error bodies go into the error text (message, error_user_title, error_user_msg, code, error_subcode, errors), with long token-like strings cut out. `setup` now reads back the webhooks (id, URL, active) and whether the Vault secret exists (a yes or no, never the value).
- **Templates.** Meta's rule that a body must not start or end with a variable is the likely cause of the 25 Oct 400 (every body started with `{{business}}`): each body now opens with "Kabsi here." Each refused template reports Meta's error fields and the others go on. `access_change` is added (name `ACCESS_CHANGE_TEMPLATE = kabsi_access_change`, a code constant); `KAPSO_TEMPLATE_ACCESS_CHANGE` is retired from `access-notice.ts` and `docs/SECRETS.md`. Examples for every variable, UTILITY, lower snake case, language `en` are tested for all ten.
- **Number health.** Alert only for YELLOW or RED quality or BLOCKED messaging (`healthIsBad`, and `public.whatsapp_health_record`, migration `20261025140000`, applied by lane R). LIMITED at tier 250 is not an alert. The email text no longer says "quality GREEN" next to "Medium or worse"; the email uses category `internal`, so it has the staff footer and not "Nothing is published until you approve it".
- **Reply parser.** `parseJson` takes the first complete JSON object; text before or after it, braces in strings and in sentences are handled (the I-008 case).
- **Evaluation.** Reply forbid patterns see negation ("we don't have", "no information", Spanish and French forms); a pattern that looks for a number is never excused; F-001's time pattern needs a holiday word in the same clause. Nora: `NOT_YET` widened (Spanish "por ahora", "todavía no", French "pour l'instant"), n64's `NOT_PROMISED` ignores a negated "guarantee".
- **Nora's rules** (`nora-rules.ts`): every hand-off gives the setup call link and hello@kabsi.co (and "Need a hand?" where the app has it); exact numbers and the dollar sign; [COMING] means "not available yet" with no date; the delete warning is the first sentence; plain text, no bold, no exclamation marks. The style check now also flags `**`.
- **Cancel on a waiting post.** `content` function action `post_cancel` finds the post's approved publication and calls `undo_publication` (the one pipeline), so the post goes back to a draft and nothing reaches Google. The Posts card shows "Cancel" on a Waiting post and "Cancelled. Nothing was posted." after it.
