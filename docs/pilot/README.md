| `setup-call.md` | The 15-minute setup call script | Rashid, on the call |
| `questions.md` | The day 30, 60 and 90 questions, and what is measured | Rashid, on each date |
| `what-kabsi-does.md` | One page for the owner: what Kabsi does and does not do | Sent before the call, and as the pilot agreement text |
